# Python Fundamentals & Logic Box 🐍

A beginner-friendly Python project to practice fundamental programming concepts through interactive terminal-based programs.

## 📌 About the Project

This project contains two Python programs designed to improve basic programming skills.

The first program collects personal information from the user, while the second program generates star patterns and analyzes numbers.

## ✨ Features

- Collect user information through keyboard input
- Display entered information and Python data types
- Show object IDs using `id()`
- Calculate an approximate birth year
- Generate star patterns using loops
- Identify even and odd numbers
- Calculate the sum of a range of numbers
- Use a menu-driven program with an exit option

## 🛠️ Technologies Used

- Python 3
- VS Code (for development)
- Terminal / Command Prompt

## 📂 Project Files

- `fundamental_pro01.py` — Personal Data Collector
- `Logic_box-Pr02.py` — Pattern Generator and Number Analyzer
- `README.md` — Project documentation

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open `fundamental_pro01.py`.
5. Run the Python program.

To run the second program, use:

```bash
python Logic_box-Pr02.py
```

You can also run the first program using:

```bash
python fundamental_pro01.py
```

## 📚 Python Concepts Learned

- Variables and data types
- `input()` and `print()`
- Type conversion
- `if`, `elif`, and `else`
- `for` and `while` loops
- `range()` function
- Arithmetic operators
- Even and odd number checking
- F-strings

The goal of this project is to build confidence in Python programming by practising basic concepts and creating simple interactive applications.
