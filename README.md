# Personal Data Collector 🐍

A beginner-friendly Python project that collects personal information from a user through the terminal.

## 📌 About the Project

The Personal Data Collector is a simple Python program created to practice fundamental Python programming concepts.

It takes information entered by the user and displays the collected details.

## ✨ Features

- Collect user information through keyboard input
- Display the entered information
- Practice Python input and output
- Build confidence with basic Python programming

## 🛠️ Technologies Used

- Python 3
- PyCharm (for development)

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in PyCharm.
4. Open `fundamental_pro01.py`.
5. Run the Python program.

## 📚 Concepts Practiced

- Variables
- Data types
- `input()` function
- `print()` function
- Basic program structure

## 🎯 Learning Objective

To understand how Python collects information from users and displays it in a simple, interactive program.
