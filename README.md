## 🚀 Featured Projects

### 1. Python Fundamentals — `fundamental_pro01.py`

**Purpose:** To understand the basic building blocks of Python programming.

**Features:**
- Accepts information from the user.
- Displays entered values.
- Demonstrates Python data types.
- Uses the `id()` function to explore object identity.
- Performs basic calculations, including an approximate birth-year calculation.

**Python concepts used:**
- Variables and data types
- `input()` and `print()`
- Type conversion
- F-strings
- Basic calculations

**Practical use:** This project helps beginners understand how Python receives, stores, processes, and displays information.

### 2. Logic Box — `Logic_box-Pr02.py`

**Purpose:** To improve logical thinking and problem-solving skills.

**Features:**
- Generates star patterns using loops.
- Checks whether numbers are even or odd.
- Calculates the sum of numbers within a range.
- Uses a menu-driven interface with an exit option.

**Python concepts used:**
- `if`, `elif`, and `else`
- `for` and `while` loops
- `range()`
- Arithmetic operators
- Nested loops and conditional logic

**Practical use:** These exercises help develop the logical foundation required for algorithms, games, data processing, and more advanced applications.

### 3. Student Data Organizer — `practical03.py`

**Purpose:** To build a menu-driven student record management system using Python.

**Planned features:**
- Add student records.
- Display all students.
- Update student information.
- Delete student records.
- Display available subjects.
- Exit the application.

**Student information may include:**
- Student ID
- Name
- Age
- Grade
- Date of birth
- Subjects

**Python concepts used:**
- Lists and tuples
- Dictionaries as a possible future improvement
- `while` loops and conditional statements
- User input and type conversion
- Searching, updating, and deleting records

**Practical use:** This project demonstrates the basic logic behind student information systems and record management applications.

**Current limitation:** Records stored only in a Python list are lost when the program closes. File or database storage can be added in a future version.

## ⚙️ How to Run the Projects

### Prerequisites

- Python 3 installed
- Visual Studio Code or another Python-compatible editor
- Git (optional, for cloning the repository)

### Step 1: Clone the Repository

```bash
git clone https://github.com/bhaveshmatrix/RnW_project.git
```

### Step 2: Open the Project Folder

```bash
cd RnW_project
```

Open this folder in Visual Studio Code.

### Step 3: Run a Project

Run the fundamentals project:

```bash
python fundamental_pro01.py
```

Run the Logic Box project:

```bash
python Logic_box-Pr02.py
```

Run the Student Data Organizer when its file is available:

```bash
python practical03.py
```

If your system uses the `py` command on Windows, you can use `py` instead of `python`.
